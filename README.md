# Мультимедийная интерактивная веб-презентация
## Тема: «Проектирование информационных систем»

Интерактивный веб-сайт-презентация, разработанный в соответствии с современными требованиями к мультимедийным образовательным и корпоративным проектам.

---

### 🌟 Ключевые особенности проекта
- **Точно 26 слайдов**:
  - **Слайд 1**: Обязательный титульный лист.
  - **Слайд 2**: Обязательный структурный план со сквозными интерактивными ссылками на все модули.
  - **Слайды 3–25**: Полный охват теории, стандартов (ГОСТ 34, ISO 12207), архитектурных стилей (монолит, микросервисы, EDA, облака), моделей проектирования (UML, BPMN), баз данных (SQL, NoSQL), безопасности, CI/CD, метрик надежности (SLA) и практического кейса e-commerce.
  - **Слайд 26**: Обязательный слайд с выводами, ключевыми тезисами и блоком Q&A.
- **Мультимедиа**:
  - Встроенное модальное окно с обучающими видеоматериалами (System Design, Microservices) и симулятором потока данных в реальном времени.
  - Синтезированные звуковые эффекты переключения слайдов (Web Audio API, без внешних mp3).
  - Интерактивный анимированный фон (нейросетевая топология на Canvas).
  - Архитектурные диаграммы и визуализации жизненного цикла (SDLC, CI/CD, Sequence Diagram).
- **Управление презентацией**:
  - Клавиатура: `→`, `Пробел`, `PageDown` — вперед; `←`, `Backspace`, `PageUp` — назад; `Home` — титул; `End` — вывод; `F` — полный экран; `O` — каталог слайдов; `M` — звук; `?` — справка.
  - Сенсорное управление: свайпы влево/вправо на смартфонах и планшетах.
  - Нижний док с 26 кликабельными индикаторами слайдов.
  - Таймер выступления в шапке.
  - Поддержка экспорта в PDF через `Ctrl + P` (стили адаптированы для печати).

### ☁️ Как бесплатно открыть презентацию в облаке (без локалки)

Проект полностью автономен и не требует базы данных или сервера. Вы можете опубликовать его бесплатно за 1 минуту:

#### Способ 1: Netlify Drop (Самый быстрый — без регистрации и команд)
1. Откройте в браузере: [https://app.netlify.com/drop](https://app.netlify.com/drop)
2. Перетащите папку `is-presentation` целиком в окно браузера.
3. Через 10 секунд вы получите готовую постоянную ссылку вида `https://ваше-название.netlify.app`, которую можно открывать на любом устройстве!

#### Способ 2: GitHub Pages (Классический вариант)
1. Создайте репозиторий на [GitHub.com](https://github.com) (например, `is-presentation`).
2. Загрузите файлы `index.html`, `style.css` и `script.js`.
3. Перейдите в **Settings** → **Pages** → в ветке выберите `main` / `root` и нажмите **Save**.
4. Сайт будет доступен по адресу: `https://ваш-логин.github.io/is-presentation/`

#### Способ 3: Vercel
1. Зайдите на [vercel.com](https://vercel.com) и авторизуйтесь через GitHub.
2. Нажмите **Add New Project**, выберите репозиторий и нажмите **Deploy**.
